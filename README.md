This project involves analyzing real-world air quality data using Microsoft Excel to gain insights into pollution trends across various Indian states and cities. 
The dataset includes parameters like PM2.5, O₃, CO, SO₂, NO₂, and other pollutants recorded over different time periods.
The project includes:

Data Cleaning & Preprocessing

Pivot Table Analysis for comparing pollutant levels across locations

Time-Series Trend Analysis using date grouping

Outlier Detection for abnormal pollution readings

Ranking of Cleanest and Most Polluted States

A custom Excel Dashboard was created to visualize key insights using charts, graphs, and conditional formatting, helping in understanding complex air quality patterns 
in a simplified, interactive way.

💡 This project helped develop strong skills in Excel functions, data manipulation, and visual storytelling using dashboards.
